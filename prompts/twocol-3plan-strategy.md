# TwoColumnSlide — 3가지 디자인 컨셉 기획서

## 설계 배경

11장을 지배하는 템플릿이므로, 3가지 컨셉은 단순한 "색감 차이"가 아닌
**정보 전달 철학의 차이**로 구분해야 한다.

---

## 차별화 축 (Differentiation Axis)

| 축 | Plan A | Plan B | Plan C |
|----|--------|--------|--------|
| 컬럼 경계 | 열린 구조 (선만) | 닫힌 구조 (카드) | 흐르는 구조 (그라디언트) |
| 시각적 무게 | 가볍다 (타이포 중심) | 중간 (면적 중심) | 강하다 (색면 중심) |
| 컬럼 관계 | 독립적 병렬 | 대등한 비교 | 서사적 흐름 (→) |
| 기하 장식 | 정밀한 점/선 | 부드러운 블러 | 유기적 곡선 |
| 참조 미학 | Swiss/Dieter Rams | Apple Keynote | Stripe/Linear |
| 의료 신뢰감 | 차트/논문 느낌 | 대시보드 느낌 | 컨설팅 덱 느낌 |

---

## Plan A: "Precision Grid" — 정밀한 여백의 힘

**한 줄 요약**: 선과 타이포그래피만으로 구조를 만드는 Swiss Design

**핵심 특징**:
- 컬럼에 배경색 없음 → 상단 3px accent border만으로 영역 구분
- 컬럼 사이 얇은 수직 구분선 (1px dashed)
- highlight는 큰 숫자로 돋보이되, 장식 없이 크기와 무게만으로
- 기하 요소: 미세한 dot grid (4~5개 점), 정밀한 hairline
- 전체적으로 "의학 논문" 같은 학술적 권위

**장점**: 어떤 콘텐츠든 깔끔, 텍스트 가독성 최고
**리스크**: 11번 반복 시 단조로울 수 있음

---

## Plan B: "Elevated Panels" — 신뢰의 깊이감

**한 줄 요약**: 부드러운 그림자와 면적으로 정보를 감싸는 Modern Card

**핵심 특징**:
- 컬럼이 독립된 카드 (rounded-2xl, subtle shadow, tinted bg)
- 좌측 카드: primary 3~5% 배경 + primary border-top 3px
- 우측 카드: secondary 3~5% 배경 + secondary border-top 3px
- highlight는 "히어로 뱃지" — 별도 배경 블록 안에 큰 숫자
- 기하 요소: 부드러운 radial gradient blur (모서리)
- 전체적으로 "프리미엄 대시보드" 같은 현대적 신뢰감

**장점**: 시각적으로 풍부, 카드가 정보를 "담아주는" 안정감
**리스크**: 카드 스타일이 기존 basic 코드와 비슷해 보일 수 있음

---

## Plan C: "Gradient Narrative" — 흐름이 있는 비교

**한 줄 요약**: 좌에서 우로 흐르는 그라디언트가 서사를 만드는 디자인

**핵심 특징**:
- 컬럼 타이틀이 gradient-backed pill (rounded badge)
- 두 컬럼을 연결하는 subtle gradient ribbon (상단 또는 하단)
- left→right 방향성이 "현재→제안", "문제→해결" 서사를 시각화
- highlight는 secondary 색상으로 강조된 대형 텍스트 + 밑줄
- 기하 요소: 유기적 곡선/아크 (SVG path), flowing dashes
- 전체적으로 "전략 컨설팅 덱" 같은 설득력

**장점**: 11장의 좌→우 서사를 시각적으로 강화
**리스크**: 장식이 과하면 콘텐츠 방해
